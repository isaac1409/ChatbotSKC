1. Dentro de la carpeta del proyecto, ejecutar
docker compose down -v
docker compose up -v

Si se llega a tener problemas correr (PERO CUIDADO PORQUE BORRA TODOS LOS CONTENEDORES):
docker system prune -a --volumes
Y confirmar con "y"

2. Para mandar llamar localhost desde docker usar el nombre de la imagen
postgres
redis
evolution_api
n8n

Ejemplo:
Si es n8n, en lugar de utilizar localhost:5678 utilizar n8n:5678

3. Para entrar en el contenedor de postgres:
docker exec -it postgres psql -U admin

4. En el archivo .env
Algunos puertos están de esta forma: - "127.0.0.1:5432:5432"
Es para que solo sean accesibles desde el servidor y no desde la red
En este caso n8n y evolutionApi sí queremos que sean accesibles desde la red para configuración
Pero redis y las bases de datos privadas y no accesibles
